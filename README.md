## خطوات التثبيت

### 1. نسخ الملفات
انسخ مجلد `sbdas_a` كاملاً إلى:
```
C:\xampp\htdocs\sbdas_a\
```

### 2. إنشاء قاعدة البيانات
- افتح XAMPP وشغّل Apache + MySQL
- افتح phpMyAdmin على: http://localhost/phpmyadmin
- افتح تبويب **Import** (من الصفحة الرئيسية، دون إنشاء قاعدة يدوياً) واختر الملف الوحيد: `sql/sbdas_database.sql`
- اضغط **Go** — الملف ينشئ قاعدة `sbdas` بنفسه (12 جدولاً + الفهارس + 14 View) ويملأها بالبيانات التجريبية، ويعرض في النهاية جدول تحقق بأعداد الصفوف
- تنبيه: الملف يحذف قاعدة `sbdas` إن كانت موجودة ويعيد بناءها

### 3. تشغيل النظام
افتح المتصفح على: http://localhost/sbdas_a/

## الوحدات المنفذة

### لوحة الإدارة العليا
- 8 مؤشرات KPI رئيسية (عملاء، حسابات، قروض، تعثر، شكاوى، إيداعات، سحوبات، تحويلات)
- رسم بياني خطي لنمو العملاء الشهري
- رسم دائري لتوزيع الإيداعات حسب الفرع
- جدول مقارنة الفروع مع تقييم الأداء

### مقارنة الفروع
- أشرطة مقارنة تفاعلية للعملاء والإيداعات
- رسم بياني شريطي مجمّع لكل المؤشرات
- جدول تفصيلي مع نسبة التعثر لكل فرع

### مؤشرات الأداء
- نسبة تعثر القروض، نسبة الشكاوى، معدل نمو العملاء
- أشرطة أداء الفروع مع ترميز لوني
- رسم بياني لحالة القروض وحجم العمليات

### التحليل المالي
- ملخص السحوبات (يومي/شهري/سنوي)
- ترتيب أكثر الحسابات تحويلاً
- ترتيب أكثر الحسابات نشاطاً
- رسوم بيانية للسحوبات وتوزيع أنواع العمليات

### التنبيهات والتوصيات
- محرك قواعد تلقائي (Rule Engine) يولّد تنبيهات حسب العتبات
- توصيات إدارية مشتقة من البيانات الفعلية
- تنبيهات النظام المدخلة يدوياً

### التقارير
- 5 أنواع تقارير: عملاء، حسابات، عمليات، قروض، شكاوى
- فلترة بالتاريخ والفرع
- دعم الطباعة

## ملاحظات تقنية
- PHP 7.4+ مع mysqli
- MySQL 5.7+
- جميع كلمات المرور في البيانات التجريبية: **password**
- النظام يستخدم RTL عربي كامل
- ملفات SQL القديمة (schema.sql وreset_full.sql والترقيعات الأربعة) دُمجت كلها في `sbdas_database.sql`
- الـ Dashboard يقرأ من Views محسوبة (لا يحسب مباشرة من الجداول الخام)
