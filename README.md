# SBDAS Lite — نظام دعم اتخاذ القرار والتحليل المصرفي للمصارف السودانية (النسخة المبسطة)

نموذج أولي (PHP + MySQL) لعرض مؤشرات أداء فروع بنك سوداني ومقارنتها وإصدار التقارير. بيانات تجريبية فقط.
هذه نسخة النشر (Vercel + Aiven MySQL)؛ خطوات النشر في `docs/DEPLOY_AR.md`.

## ما الذي تغيّر في هذه النسخة عن السابقة
- 11 جدولاً فقط بلا Views ولا جدول إشعارات (+ جدول `sessions` لنسخة النشر وحدها).
- حذف صفحة التحليل الرقمي؛ تبقى الإجماليات في الشريط الرقمي (7 مؤشرات) بلوحة الإدارة العليا، وتفصيلها صار تقريرين في صفحة التقارير: «نشاط تطبيق الجوال (شهرياً)» و«الحركة مع البنوك الأخرى (حسب البنك)». لا تتكرر المعلومة بين الشريط والتقارير (إجماليات هناك، تفصيل هنا).
- قالب واحد `includes/layout.php`، ومحرّكان مشتركان: `includes/financial.php` (التحليل المالي) و`includes/reports.php` (التقارير)، يعملان بنطاق الفروع كلها أو فرع واحد.
- حذف صفحة الإشعارات وملفات المعالجة المنفصلة (add_user / toggle_user): صارت داخل `pages/admin/users.php`.
- 10 صفحات بدل 15، وأسطر PHP أقل بنحو 75%.

## الصفحات
| الدور | الصفحات |
|---|---|
| الإدارة العليا | لوحة المؤشرات، مقارنة الفروع، التحليل المالي، التقارير |
| مدير الفرع | لوحة الفرع، التحليل المالي للفرع، تقارير الفرع (فرعه فقط) |
| مدير النظام | لوحة النظام، الفروع، المستخدمون |

الخصوصية: لا تُعرض أسماء العملاء ولا الهويات ولا الهواتف؛ يُكتفى برقم الحساب.

## التشغيل المحلي (XAMPP)
1. انسخي المجلد إلى `C:\xampp\htdocs\sbdas_lite\` وشغّلي Apache وMySQL.
2. أنشئي قاعدة فارغة باسم `sbdas` واستورِدي `database/database.sql`.
3. افتحي http://localhost/sbdas_lite/login.php

كلمة مرور الحسابات في ملف القاعدة الأصلي للتشغيل المحلي هي `password`؛ أما ملف النشر هذا فكلمات المرور فيه عشوائية مجهولة، والدخول يتم بزرّي الدخول التجريبي (DEMO_LOGIN=1) أو بتعيين كلمة مرور عبر `tools/sbdas_tools.ps1` الخيار 2.

## ملفات المستودع
```
index.php  login.php  logout.php
api/index.php          ← نقطة دخول Vercel (قائمة بيضاء للمسارات)
includes/              ← db_conn، db، auth، session_handler، layout، financial، reports، init
pages/{executive,branch_manager,admin}/
public/{css,img}/      ← الملفات الساكنة
database/database.sql  ← القاعدة (11 جدولاً + sessions)
tools/                 ← استيراد / كلمة مرور / ترحيل (sbdas_tools.ps1)
```
