# نشر SBDAS على GitHub + Vercel + Aiven

الفكرة نفسها المستخدمة مع SNTMP: **GitHub** يحفظ الشيفرة ← **Vercel** يشغّل الموقع ← **Aiven MySQL** يحفظ البيانات. الجلسات تُحفظ في جدول `sessions` بالقاعدة لأن Vercel لا يحتفظ بملفات.

## ما يميّز هذه النسخة
- صفحة الدخول فيها زرّان: **الدخول إلى واجهة الإدارة العليا** و**الدخول إلى واجهة مدير الفرع** بدون اسم مستخدم أو كلمة مرور (يعملان فقط عند `DEMO_LOGIN=1`، ولحسابين محددين فقط: `executive` و`manager1`).
- كلمات مرور المستخدمين في القاعدة عشوائية غير معروفة، فلا يمكن لأحد الدخول بـ admin/password. حساب مدير النظام غير متاح للدخول إلا إن عيّنتِ له كلمة مرور بالأداة (الخيار 2).
- صفحات الإدارة العليا ومدير الفرع للقراءة فقط (لا توجد فيها عمليات تعديل)، فلا يستطيع أحد من الزوار تغيير البيانات.
- حُذف `setup.php` (أداة التشخيص المحلية) من هذه النسخة.
- المشروع الأصلي في `C:\xampp\htdocs\sbdas_a` لم يتغير.

## الخطوات (يدوية لأنها حساباتك)
1. **قاعدة البيانات (Aiven):** استعملي خدمة MySQL نفسها المستخدمة مع SNTMP، فالخطة المجانية تسمح بخدمة MySQL واحدة. تُنشأ قاعدة **جديدة** باسم `sbdas` داخلها، ولا تُمسّ `defaultdb` الخاصة بـ SNTMP. شغّلي `tools\sbdas_tools.ps1` واختاري **1**.
2. **GitHub:** أنشئي مستودعاً **خاصاً** فارغاً (بلا README) باسم `SBDAS`، ثم شغّلي `push_to_github.ps1` وأدخلي رابط المستودع.
3. **Vercel:** Add New ← Project ← اختاري المستودع ← Framework Preset = Other ← أضيفي المتغيرات حسب `tools\vercel_env_vars_TEMPLATE.txt` ← Deploy.
4. افتحي الرابط واضغطي أحد الزرّين.

## متغيرات Vercel
`DB_HOST` `DB_PORT` `DB_USER` `DB_NAME=sbdas` `DB_PASS` (Sensitive) `DB_SSL=1` `DB_SSL_CA_PEM` `APP_BASE_URL=/` `SESSION_STORE=db` `DEMO_LOGIN=1`

## ملاحظات
- Chart.js يُحمَّل من CDN (jsdelivr)؛ يلزم اتصال إنترنت لرؤية المخططات.
- لإيقاف الدخول التجريبي: احذفي `DEMO_LOGIN` (أو اجعليه 0) ثم Redeploy، فتختفي الأزرار.
- خدمة Aiven المجانية قد تُطفأ عند الخمول؛ شغّليها من لوحة Aiven إن لم يفتح الموقع.
